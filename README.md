### Project Description
OBSERVE is an interactive AI-based eye-tracking experiment that monitors blinking and eye movement through a webcam.The virtual eyes follow the user's gaze while becoming increasingly irritated and teary over 20 seconds.It is a deliberately useless but entertaining project designed to showcase computer vision and interactive web technology.

### The Problem (that doesn't exist)
OBSERVE ensures you waste 20 seconds of your life proving you can maintain eye contact with two digital eyes.No real-world problem was solved—but at least your blinking was judged. 💀

### The Solution (that nobody asked for)
Make people stare at two digital eyes until they question their life choices.AI tracks their eyes and blinks in real time, because apparently even blinking needs supervision.In short: we solved nothing—but we did it with AI. 🤡

## Implementation

### For Software:

# Installation

No special installation is required. Make sure you have:

- Visual Studio Code
- Live Server extension
- A modern web browser
- A working webcam
- Internet connection for MediaPipe and audio resources

Open the project folder in VS Code and run it using **Live Server**.

# Run

Right-click `index.html` → **Open with Live Server**

Or use:

```text
http://127.0.0.1:5500/
```
